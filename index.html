SF Architect Agent

סוכן ארכיטקט שמכיר את ה-org שלך — מקבל אפיון פונקציונלי, צולב מול המצב הקיים והעתידי, ומפיק TSD ארכיטקטוני מלא עם ניתוח השפעה והחלטות.

מה הכלי הזה עושה?

1

קולט שלושה דברים

מסמך אפיון פונקציונלי (FSD בעברית), מצב נוכחי של ה-org (deployed.json) ואפיונים בתהליך (in-flight.json).

2

חושב כארכיטקט

מצליב כל דרישה מול המצב — מסווג כל פריט ל-REUSE / EXTEND / CREATE / CONFLICT. מזהה קונפליקטים לפני העיצוב.

3

מפיק TSD מלא

שמונה קבצים: סיכום מנהלי, אובייקטים, שדות, אוטומציות, הרשאות, UI, אינטגרציות, וקובץ ניתוח השפעה עם ADRs וסיכוני ארכיטקטורה.

4

מעדכן את הזיכרון

מפיק in-flight-updated.json — עם הרכיבים החדשים שתוכננו — מוכן לשימוש בהרצה הבאה.
